# Kaviyarasi Selvaraj — Personal Portfolio

A modern, responsive personal portfolio website showcasing professional profile, technical skills, projects, certifications, and coding journey.

## Overview

This is a fully-featured personal portfolio website built with vanilla HTML, CSS, and JavaScript. It showcases a computer science engineering student's professional profile, technical expertise, academic achievements, and project portfolio. The site features a clean, dark-themed design with smooth navigation and interactive content management.

## ✨ Highlights

* **Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices
* **Skills Showcase** — Organized technical skills across programming, web development, and core competencies
* **Projects Gallery** — Display and manage software projects with descriptions and technologies
* **Certifications & Workshops** — Highlight professional certifications and training achievements
* **Social Integration** — Links to coding profiles (GitHub, LeetCode) and professional networks (LinkedIn)
* **Resume Access** — One-click resume download functionality
* **Content Management** — Add, edit, and delete portfolio items directly from the site
* **Dark Theme** — Modern, eye-friendly interface with smooth animations

## 🛠 Technologies

* HTML5
* CSS3
* JavaScript (Vanilla)
* Browser localStorage for data persistence

## 📑 Portfolio Sections

| Section | Description |
|---------|-------------|
| **About** | Professional introduction with personal statement and social links |
| **Skills** | Technical skills organized by category (Programming, Web Development, Core Competencies, Tools & Platforms) |
| **Projects** | Software projects with descriptions, features, and technology stack |
| **Certifications** | Professional certifications and formal training achievements |
| **Workshops** | Relevant workshops and training programs completed |
| **Contact** | Social media links and email contact information |

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/kaviyarasi-Selvaraj/portfolio.git
   cd portfolio
   ```

2. Open in your browser:
   - Double-click `index.html`, or
   - Use a local server (recommended):
     ```bash
     python -m http.server 8000
     ```
   - Visit `http://localhost:8000` in your browser

3. Navigate using the menu or scroll through sections
